# Hospital Horror Game Wiki

Independent beginner-first guide for **Hospital Horror Game!** on Roblox.

- Production domain: `https://hospitalhorrorgame.wiki`
- Roblox Place ID: `113046448920073`
- Roblox Universe ID: `10610155567`
- Cloudflare Worker: `hospital-horror-game-wiki`

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm test
npm run deploy:dry-run
```

## Production deployment

```bash
npm run deploy
```

Custom-domain DNS and Search Console are completed separately after an explicit browser and DNS release.
